# Curriculum Coverage Matrix: Klasse 1–12 → L1–L3

This document maps the German secondary school mathematics curriculum (Klasse 1–12)
to the SOR archive taxonomy (Level 1–3). It serves as a reference for the
Lehrplan page (`app/lehrplan.html`) and as the authoritative guide for which
archive sections cover each school year.

The mapping reflects the typical German/Bavarian Gymnasium curriculum. Exact topic
order may differ by state (Bundesland) and school type, but the overall progression
is representative across all German-language curricula.
