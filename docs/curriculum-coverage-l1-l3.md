# Lehrplan-Abdeckungsmatrix: Klasse 1–12 → L1–L3 Archivabschnitte

Richtet sich am typischen Gymnasiallehrplan aus (Bayern/NRW/BW).  
Leichte Abweichungen je Bundesland möglich. Klasse 13 = Abiturjahr im G9-System.

Maschinenlesbare Version: `app/data/curriculum-matrix.js` (→ `window.SOR_CURRICULUM_MATRIX`)

## Abdeckungsübersicht L1–L3

| Archiv-Level | Schulbereich | Klassen |
|---|---|---|
| 🟢 L1 – Grundlagen | Grundschule + Unterstufe | 1–6 |
| 🟡 L2 – Aufbauwissen | Mittelstufe Gymnasium | 7–10 |
| 🟠 L3 – Vertiefung | Oberstufe / Abitur | 11–12 |
| 🔵 L4+ | Universität / Studium | jenseits Schule |

## Nicht abgedeckte L3-Abschnitte (fortgeschrittenes Abitur / Übergang L4)

Die folgenden Archivabschnitte gehen über den Standardlehrplan hinaus und dienen als Brücke zu L4:

- **3.3.1.b** – Polarform und Eulersche Formel (eher L4-Einstieg)
- **3.4.1.a/b** – Matrizen (bundeslandabhängig, Übergang zu L4)
- **3.5.1.a** – Kegelschnitte (Parabel, Ellipse, Hyperbel) – analytische Geometrie, oft Übergang

## Verwendung in der App

```js
// Empfohlene Archivebene für Klasse 8
SOR_CURRICULUM_MATRIX.archiveLevelForKlasse(8); // "L2"

// Alle primären Abschnitte für Klasse 10
SOR_CURRICULUM_MATRIX.sectionsForKlasse(10);
// ["2.2.1", "2.3.3", "2.4.1.b", "2.4.2.a", "2.4.3.a"]

// Welche Klassen behandeln Abschnitt 2.1.3 (quadratische Gleichungen)?
SOR_CURRICULUM_MATRIX.klassenForSection("2.1.3"); // [9]
```
