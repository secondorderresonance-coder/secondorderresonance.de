# Curriculum Coverage Matrix – Klasse 1 bis 12

This document maps every core topic of the German mathematics curriculum
(Klasse 1–12) to the corresponding L1–L3 archive sections in the Second
Order Resonance learning platform.

It serves as the authoritative reference for:
- ensuring the archive covers all relevant school-level topics
- deep-linking placement test results into the right sublevel
- guiding future seed-task additions for underrepresented topics

Mapping notation:
- **Archive sublevel id** refers to `SOR_ARCHIVE.taxonomy[level].sublevels[].id`
- Coverage status: ✅ = seed tasks exist · ⚠️ = partial / thin · ❌ = not yet covered

## Verwendung dieser Matrix

**Für den Platzierungstest:**
Map das Testergebnis `(level, sublevel)` auf das entsprechende Schulstufen-Band
aus dieser Tabelle, sodass der Nutzer ein Feedback wie
„Du befindest dich auf Klasse-9-Niveau (L2 / Quadratische Gleichungen)" erhalten kann.

**Für den Lernpfad (Lernstrasse):**
Jede `roadLesson` in `app/lernpfad.html` wählt ihre Aufgaben anhand von
`level + sublevel + topic` aus dem Archiv. Diese Matrix stellt sicher,
dass die Reihenfolge der Lernstrassen-Lektionen der Schullehrplan-Progression folgt.

**Für die Archiv-Erweiterung:**
Priorisiere Seed-Task-Batches anhand der ⚠️- und ❌-Lücken oben,
beginnend mit den kritischen Lücken auf Kl. 5–6-Niveau (L1 Unterstufe).
