# Curriculum Coverage Matrix – Klasse 1-12

Mapping of the German school mathematics curriculum (Klasse 1-12) to SOR archive sections (L1-L3).

Each SOR archive section now carries a `gradeRange` field in the taxonomy so the Lernstrasse can display the matching school grade span per section.

## Gap analysis

No structural gaps identified for Klasse 1-12 coverage in the current taxonomy.

| Thema | Klasse | Hinweis |

| Abbildungsgeometrie (Drehen, Verschieben) | 6–7 | Teilweise in 1.2.4.a enthalten |
| Lineare Optimierung / Graphen | 10 | Teilweise in 2.1 behandelt |
