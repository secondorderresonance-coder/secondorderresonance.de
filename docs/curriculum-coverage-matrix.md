# Curriculum Coverage Matrix: Klasse 1–12 → L1–L3

## Zweck

Diese Matrix bildet den deutschen Mathematik-Lehrplan der Klassen 1–12 auf die
bestehenden L1–L3 Archivabschnitte ab.  Sie dient als Referenz fuer:

- gezielte Lernpfad-Empfehlungen je nach Jahrgangsstufe
- Identifikation von Luecken im Archiv
- priorisierte Erweiterungsbatches fuer Klassen-relevante Seed-Tasks

Level-Zuordnung nach Jahrgangsstufe (Faustregeln):

| Jahrgangsstufen | Haupt-Level |
|-----------------|-------------|
| 1 – 4           | L1          |
| 5 – 6           | L1 (vertieft) |
| 7 – 8           | L1 → L2     |
| 9 – 10          | L2          |
| 11              | L2 → L3     |
| 12              | L3          |
