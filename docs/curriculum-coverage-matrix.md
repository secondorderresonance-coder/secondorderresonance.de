# Curriculum Coverage Matrix – Klasse 1–12 → L1–L3

This matrix maps every major topic of the German school curriculum (Klasse 1–12)
to the corresponding archive sublevel in the SOR learning taxonomy.

Use it to:
- identify content gaps in the archive seed tasks
- plan new seed-task batches for specific school grades
- verify that the archive covers the full school-level learning path
