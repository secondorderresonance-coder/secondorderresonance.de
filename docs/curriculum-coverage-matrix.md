# Curriculum Coverage Matrix – Klasse 1–12 → L1–L3 Archive Sections

Version: v2.6.0  
Last updated: 2026-05-28

This document maps the German Gymnasium/Gesamtschule curriculum (Klasse 1–12) to the corresponding L1–L3 archive sections in the SOR learning platform. It is the authoritative reference for identifying coverage gaps and planning future seed-task batches.

## Level–Grade Mapping Overview

| Grade cluster      | SOR Level         | Description                      |
|--------------------|-------------------|----------------------------------|
| Klasse 1–4         | L1 (Grundlagen)   | Grundschule                      |

| Klasse 7–8         | L2 (Aufbauwissen) | Mittelstufe                      |

| Klasse 11–12       | L3 (Vertiefung)   | Oberstufe / Abiturniveau         |
