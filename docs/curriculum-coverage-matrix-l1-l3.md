# Curriculum Coverage Matrix: Klasse 1–12 → L1–L3 Archive Sections

## Purpose

This matrix maps the standard German mathematics curriculum (Klasse 1–12, Gymnasium)
to the corresponding L1–L3 archive sections in the SOR platform.

It serves as the authoritative reference for:
- designing the Lernstrasse (which archive sublevels appear in which school year)
- gap analysis (which curriculum topics are already covered, which still need seed tasks)
- onboarding new users (mapping their grade to the right archive entry point)

The mapping follows the Gymnasium path (Bayern / KMK-Rahmenplan).
Realschule and other school types follow the same progression up to Klasse 10 with fewer topics.

## Notes on Federal State Variations

- **Bayern (G8/G9)**: This matrix follows the Gymnasium-Bayern structure.
  Complex numbers and matrices appear in Klasse 12–13. Klasse 9 includes first analysis topics.
- **NRW (G9)**: Broadly similar; analysis starts in Q1 (Klasse 10/11).
  Stochastics more prominent in Abitur.
- **Baden-Württemberg**: Analysis in Klasse 10 earlier.
  Vectors can appear in Klasse 10 already.

The L1–L3 archive coverage is sufficient for all major federal states since it maps
all topics without tying them to a single state's exact progression.
