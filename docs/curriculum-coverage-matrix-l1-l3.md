# Curriculum Coverage Matrix: Klasse 1–12 → L1–L3 Archive Sections

## Purpose

This matrix maps the standard German school mathematics curriculum (Klasse 1–12)
to the corresponding L1–L3 archive sections in the SOR taxonomy.
It serves as:
- a gap-analysis reference for archive content expansion
- a guide for placing new seed tasks in the correct sublevel
- a transparency document showing which school years are covered

The scope is L1 (Grundschule und Unterstufe), L2 (Unter- und Mittelstufe),
and L3 (Oberstufe und Schulabschlussniveau).

## Archive expansion priorities inferred from this matrix

Topics where the archive already has seed tasks (see `archive-content.js` T-1-xxx, T-2-xxx, T-3-xxx)
are marked as covered. Topics without dedicated seed tasks are candidates for the next content batches.

### L1 gaps (Klasse 1–4 focus)
- Klasse 1-2 counting and number-line tasks (1.1.1.a) — few tasks dedicated to Grundschule level
- Symmetry and visual geometry (1.2.3.b) — no dedicated seed tasks yet

### L2 gaps (Klasse 5–10 focus)
- Betragsungleichungen (2.1.4.b) — thin coverage
- Tangensfunktion (2.4.3.b) — may need more tasks
- Sehnen und Tangenten (2.5.2.b) — no dedicated seed yet

### L3 gaps (Klasse 11–12 focus)
- Linearisierung und Näherungen (3.1.1.d) — may be thin
- Kegelschnitte (3.5.1.a) — only one entry, few examples

## How to use this matrix

1. **Adding new seed tasks**: pick a row from the appropriate Klasse, find the archive sublevel,
   and follow the seed-task template in `docs/archive-content-qa-workflow.md`.
2. **Archive QA**: run `node tools/archive-qa.js` after adding new content to verify
   taxonomy IDs remain valid and task counts stay balanced.
3. **Engineering matrix**: for Klasse 13+ (university level), see
   `docs/curriculum-coverage-matrix-l4-l5.md` (to be created).
