---
name: website-iteration
description: Use this skill when improving the Second Order Resonance website iteratively through small, reviewable repository changes.
---

1. Read AGENTS.md, BACKLOG.md, and STATUS.md first.
2. Select exactly one highest-priority open task.
3. Keep the implementation small and preserve the current design language.
4. Prefer reusable structures over hardcoded one-off solutions.
5. Validate the affected area.
6. Update STATUS.md and BACKLOG.md before finishing.
